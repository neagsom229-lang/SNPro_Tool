1 = one frame every second of footage. Use a decimal like 0.5 for one frame every 2 seconds.

How it works

  1. We read your video frame by frame using OpenCV.
  2. Frames are saved as JPEG images.
  3. All frames are packed into a ZIP file.
  4. Download and extract – each frame is named sequentially.
